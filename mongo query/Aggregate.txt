Aggragation  in  MongoDB is a way  to Process data and Treansform it  into a meaningful  results - instead of just fetching a raw documents

Aggragation = Data flow from step by step (Pipeline) -  each stage transform a data 


=================================================
aggregate([])  array of stages  stages is {} object
===================================================
some stages names are 
$match  =   filter
$project=     select/reshape fields  
$group  = group via  _id (group+calculat) or id=null
$sort   =  sort  result -1 or 1 
$limit  =   limit result 
$skip   =   skip result 
$unwind =  convert array items into  documents 
$lookup =  join another collection  similer sql join 
$count  =  ount document 
$addFields= add/calculate fields

Calculate the total orders for each gender.
db.costomerLarge.aggregate([
  {
    $group:{
      _id:"$gender",
      totalOrders:{
        $sum: "$totalOrders"
      }
    }
  },{
    $project:{
      _id:0,
      gender: "$_id",
      totalOrders: 1
    }
  }
])
