//regular expressions 
$regex     in btn /..../
mostly used  in pattern based  searching 
 pattern based matching is a searching  data based on patterns instead  of exact values 

 $regex is  used for pattern matching in queries 
 $options  is used to modify  behaviour

 ^  = start  with   ^S   "Sujan", "sujal"
 $ ends with  i$   "Panthi"
 .*     anything in between   ^S.*n$ = Sujan  
 
 find    costomer  whone name start  with "S"
((((((((((((((   regex is case sensetive  but id use /i    like  /s/i   give   Sujan Sujan         ))))))))))))))


db.users.find({
    name:{$regex:/^S/i}
})
